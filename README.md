# CoP_Cordaje V2
Preparado para https://marticj57-dev.github.io/CoP_Cordaje/

1. Descomprime el ZIP.
2. Sube su contenido al nivel principal del repositorio `CoP_Cordaje`.
3. Conserva las carpetas `.github`, `public` y `src`.
4. En Settings > Pages selecciona GitHub Actions.
5. Espera a que el flujo de Actions termine en verde.
6. Abre la URL e instala desde el menú de Chrome.

Si ves la versión antigua, borra los datos de `marticj57-dev.github.io` en la configuración de sitios de Chrome y vuelve a abrir la URL.
